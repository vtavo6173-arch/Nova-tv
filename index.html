NovaTV

Entretenimiento en Roku

NovaTV es un proyecto independiente en desarrollo para dispositivos Roku.

Su objetivo es organizar y mostrar información de películas y series, incluyendo títulos, sinopsis, imágenes, géneros y fechas de estreno.

El proyecto utiliza TMDB para consultar información de películas y televisión.

Proyecto en desarrollo.

Este producto utiliza la API de TMDB, pero no está respaldado ni certificado por TMDB.
